# Al Abeer × Zoho CRM Plus — Visual Implementation Guide

Professional Next.js website for Hallek to present and implement the Al Abeer Zoho CRM Plus solution.

## Run locally

```bash
cd abeer-zoho-guide
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Overview, goals, waves, lead journey |
| `/architecture` | System architecture + data boundary |
| `/flows` | Lead, assignment, HIS sequence, reactivation |
| `/apps` | Zoho apps + integrations table |
| `/roadmap` | BRD phases + gantt |
| `/implement` | Full micro-step runbook |
| `/checklist` | Interactive tick-off progress tracker |

## Build

```bash
npm run build
npm start
```
